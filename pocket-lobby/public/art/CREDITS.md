# Tower adventurer artwork

The Tower adventurer is adapted from **Isometric Modular Character Pack (Male & Female)** by **feyza5**:
https://feyza5.itch.io/isometric-modular-character-pack-male-female

The original pack permits personal and commercial project use and modifications. It prohibits resale, redistribution or repackaging of the assets as standalone assets or asset packs. See the creator's page for the full terms.

Included here are game-specific runtime atlases only. The original asset archive and Aseprite source files are not included. The Tower jacket, insignia, boots, articulated activity poses, palette system, equipment anchors and game integration are modifications for Tower of Beginnings. The original character artwork remains credited to feyza5. No generative image tool was used to produce these derivatives.

Atlas format: 80 x 100 cells, 57 poses in each of four diagonal directions (SW, SE, NE, NW), at half scale in world coordinates. The JSON stores animation ranges and per-frame hand anchors. Material pixels encode the garment and colour-ramp level so existing saved outfits can recolour the character at runtime.
