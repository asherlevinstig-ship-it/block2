# Kenney Fantasy UI Borders

This folder contains a deliberately small subset of Kenney's **Fantasy UI Borders** pack used by the shared RPG modal system.

- Source: https://kenney.nl/assets/fantasy-ui-borders
- License: Creative Commons CC0 1.0
- Included: one 9-slice transparent frame and one fading divider

The full pack was not bundled so the game only ships the two assets it uses.
