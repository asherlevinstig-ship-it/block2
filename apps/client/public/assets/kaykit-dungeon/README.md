# KayKit Dungeon Remastered — curated Floor 1 subset

Source: https://github.com/KayKit-Game-Assets/KayKit-Dungeon-Remastered-1.0

Pinned source revision: `b0ca9bd96a8072ab36a3a5464f00ed1e06a16d07`

License: CC0 1.0. The upstream `LICENSE.txt` is included beside these files.

Only the eleven model types used by Tower Floor 1 are shipped. This keeps the
download below 0.7 MB before transfer compression instead of bundling the full
source pack. The GLBs are upstream files without geometry or texture changes.

Gameplay collision, navigation and encounter state remain server-owned. These
models are visual replacements with the procedural world retained as a loading
and failure fallback.
