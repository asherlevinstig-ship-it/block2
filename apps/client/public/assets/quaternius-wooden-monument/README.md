# Quaternius Wooden Monument

This directory contains the authored monument used by the Tower Chronicle in the Town of Beginnings.

- Model: Wooden Monument
- Creator: Quaternius
- Source: https://poly.pizza/m/QBTCfwOTsY
- Original file: https://static.poly.pizza/5e754dc8-8969-4934-8a00-f2715c58ac92.glb
- License: Creative Commons Zero (CC0 1.0)
- Format: binary glTF (`.glb`)
- Original triangle count: 4,272

The model provides the permanent tower-and-flags silhouette. Server-owned collision and the game's dynamic floor trophies, locks, progress label and victory bell remain separate so progression can change without modifying the source mesh.
