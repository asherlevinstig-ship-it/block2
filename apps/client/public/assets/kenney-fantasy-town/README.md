# Kenney Fantasy Town Kit 2.0

This directory contains the curated subset of Kenney's Fantasy Town Kit used by the fast low-poly Town of Beginnings. It includes complete modular building pieces as well as town props.

- Source: https://kenney.nl/assets/fantasy-town-kit
- Creator: Kenney (https://kenney.nl)
- Version: 2.0, released 2025-08-03
- License: Creative Commons Zero (CC0 1.0)
- Format: binary glTF (`.glb`)

The original `LICENSE.txt` is included beside the models. Models are loaded as render entities; authoritative gameplay collision remains in Blockcraft's server-owned town footprints.
