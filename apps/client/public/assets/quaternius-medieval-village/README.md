# Quaternius Medieval Village Pack

This directory contains the curated complete-building subset used by the fast-mode Town of Beginnings.

- Creator: Quaternius
- Source: https://quaternius.com/packs/medievalvillage.html
- Browser-ready distribution: https://poly.pizza/bundle/Medieval-Village-Pack-NsHhjhlrfY
- License: Creative Commons Zero (CC0 1.0)
- Format: binary glTF (`.glb`)

The game uses complete authored buildings rather than reconstructing houses from independently scaled wall and roof modules. Gameplay collision remains server-owned and is aligned with each building placement.
